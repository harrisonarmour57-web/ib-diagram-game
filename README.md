# Shift Happens

An arcade game for IB Economics diagrams (Paper 2 and Paper 3, AO2 and AO4, SL and HL): drag curves, drop labels, hunt the welfare loss and crunch HL numbers against the clock.

Play it at https://harrisonarmour57-web.github.io/ib-diagram-game/

Sister site: [IB Diagram Drill](https://harrisonarmour57-web.github.io/ib-diagram-drill/), which shares the same diagram bank.

`index.html` is a single self-contained page built from the project source.
